# SWASTHRA Health

Build SWASTHRA — Smart Women's Health Screening & Risk Assessment, a functional SIH 2026 prototype for smartphone-based non-invasive anemia screening for community health workers. Include landing page, CHW authentication with demo mode, dashboard with live stats, beneficiary registration and profiles, guided health questionnaire, guided image capture with camera/upload, automated image quality assessment, AI screening processing stage with clean API integration architecture for Python/FastAPI ML backends, multi-factor preliminary risk assessment engine (Low/Moderate/High preliminary risk with non-diagnostic disclaimers), referral creation and tracking, follow-up scheduling and reminders, searchable screening history and beneficiary directory, notifications, responsive mobile-first UI with large touch targets, and full mock/persisted workflow from registration to follow-up.
